# ERP система для детейлинга SPRauto.by

## О проекте

SPRauto ERP — это специализированная ERP/CRM система для детейлинговых центров, разрабатываемая на основе реальных бизнес-процессов действующего премиального детейлинг-центра SPRauto.by.

Цель проекта — создать лучшую специализированную систему управления детейлингом в Беларуси и РФ с дальнейшим масштабированием на сеть студий, франшизы и оптовое направление.

Проект создается не как универсальная CRM, а как глубоко специализированная экосистема именно под:

* оклейку антигравийными пленками
* тонировку
* шумоизоляцию
* детейлинг
* антихром
* полировку
* керамику
* оптовую продажу пленок и материалов
* управление производством
* управление персоналом
* финансовую аналитику
* складской учет
* клиентский сервис
* автоматическое формирование документов

---

# Основная философия проекта

Система должна:

* работать быстро
* быть максимально понятной визуально
* минимизировать ручной ввод
* исключать потерю данных
* автоматизировать расчеты
* быть удобной как для собственника, так и для сотрудников
* работать как единое окно управления компанией

Главная задача:
создать систему, через которую можно полностью управлять детейлингом:
от первого сообщения клиента до анализа чистой прибыли бизнеса.

# О проекте SPRauto ERP

SPRauto ERP — специализированная ERP/CRM система для детейлинговых центров.
Разрабатывается на основе реальных бизнес-процессов SPRauto.by (Беларусь).

Цель — лучшая система управления детейлингом в Беларуси и РФ.
Перспектива — масштабирование на сеть студий, франшизы, оптовое направление.

## Специализация системы
- Оклейка антигравийными плёнками (PPF)
- Тонировка
- Шумоизоляция
- Детейлинг, полировка, керамика, антихром
- Оптовая продажа плёнок и материалов

## Философия
- Работать быстро
- Минимизировать ручной ввод
- Исключать потерю данных
- Автоматизировать расчёты
- Единое окно управления компанией

## Модули (план)
1. CRM — клиенты, лиды, заказы (физ/юр лица)
2. Заказы — статусы, услуги, материалы, исполнители
3. Финансы — выручка, прибыль, касса, ДДС, дебиторка
4. Бонусы — расчёт по ролям, KPI, несколько менеджеров
5. Склад — плёнки, расходники, списание на заказ
6. Документы — договоры, акты, PDF автогенерация

## Клиент (физ. лицо)
ФИО, телефон, паспорт, VIN, марка, модель, госномер, источник лида

## Клиент (юр. лицо)
Название, УНП, юр. адрес, банк. реквизиты, директор, контактное лицо

## Заказ содержит
Номер, статус, услуги, комплекс, материалы, стоимость,
оклейщики, менеджеры, сроки, документы, фото, комментарии

## Финансы считают автоматически
Выручку, валовую/маржинальную/операционную/чистую прибыль,
CS Ratio, прибыль по направлениям, кассу, безнал, дебиторку, ФОТ
